<h2 id="about-the-project">📖 About The Project</h2>
<p>
  <b>Email Automation System</b> ek Python-based solution hai jo aapke daily repetitive emails bhejne ke kaam ko aasan aur fast banati hai. Yeh system dynamic email bodies, attachments, aur recipient lists (CSV/Excel) ko easily handle karta hai.
</p>

<hr />

<h2 id="key-features">⚡ Key Features</h2>

<table>
  <tr>
    <th>Feature</th>
    <th>Description</th>
  </tr>
  <tr>
    <td><b>⚡ Bulk Emailing</b></td>
    <td>Ek sath hazaron recipients ko bina kisi delays ke emails send karein.</td>
  </tr>
  <tr>
    <td><b>📁 Attachment Support</b></td>
    <td>PDFs, Images, aur Documents ko automated emails ke sath attach karein.</td>
  </tr>
  <tr>
    <td><b>📊 Log Tracking</b></td>
    <td>Sent aur failed emails ki mukammal reporting aur history record rakhein.</td>
  </tr>
  <tr>
    <td><b>🔒 Secure SMTP</b></td>
    <td>App Passwords aur Environment Variables ke zariya secure login system.</td>
  </tr>
</table>

<h2 id="tech-stack">🛠️ Tech Stack</h2>

<ul>
  <li><b>Programming Language:</b> Python 3.x</li>
  <li><b>Core Modules:</b> <code>smtplib</code>, <code>email.mime</code>, <code>ssl</code></li>
  <li><b>Data Processing:</b> <code>pandas</code> / <code>csv</code></li>
</ul>

<h2 id="getting-started">🚀 Getting Started</h2>

<h3>1. Clone the Repository</h3>
<pre><code>git clone https://github.com/mahtabhussainofficial/email-automation-system.git
cd email-automation-system</code></pre>

<h3>2. Install Dependencies</h3>
<pre><code>pip install -r requirements.txt</code></pre>

<hr />

<h2 id="usage">💻 Usage</h2>

<p>Apne credentials aur message configuration set karne ke baad script run karein:</p>

<pre><code>python main.py</code></pre>

<hr />

<h2 id="security-note">🛡️ Security Note</h2>
<blockquote>
  <p><b>Important:</b> Kabhi bhi apna real email password code mein push na karein. Gmail ke liye hamesha <b>App Password</b> aur <code>.env</code> file ka istemal karein.</p>
</blockquote>
